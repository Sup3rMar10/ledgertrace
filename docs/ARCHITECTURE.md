# Architecture

```
 Browser: web/index.html + app.js + style.css   (textContent / SVG attributes only, CSP script-src 'self')
    |  JSON over HTTP, httpOnly SameSite=Strict cookie, X-CSRF-Token on POST
    v
 app.py  FastAPI on 127.0.0.1:8002 (Host allow-list, CORS = localhost, rate limits, argon2)
    |
    +-- analysis.py  Ledger (in-memory view), clusters, change detection, patterns, taint trace, risk
    v
 ledgertrace.db (SQLite, parameterised queries only)
    ^
    +-- sim.py  deterministic simulated UTXO ledger (made-up labels), loads DB, runs analysis.run_all
```

## API

| Method | Path | Auth | Purpose |
|---|---|---|---|
| POST | /api/register, /api/login | none, rate limited | Create account / start session, returns CSRF token |
| POST | /api/logout | session + CSRF | End session |
| GET | /api/me | session | Current user and CSRF token |
| GET | /api/stats | session | Counts plus flagged seed transactions |
| GET | /api/patterns?kind= | session | Peel chains, fan-outs, fan-ins, CoinJoin-style txs |
| GET | /api/risk?limit= | session | Highest-risk addresses with reasons |
| GET | /api/address/{addr} | session | Label, cluster, balance, risk, recent txs |
| GET | /api/tx/{txid} | session | Inputs and outputs with spend links |
| POST | /api/cases | session + CSRF, 20/min | Trace taint from a seed output, store case |
| GET | /api/compare?txid&vout&hops | session | Poison vs haircut vs FIFO exposure side by side |
| GET | /api/cases, /api/cases/{id} | session | Own cases / one case with graph and hits |
| GET | /api/cases/{id}/report.md | session | Markdown report download |

## Database

```
users, sessions                                           -- as in the other projects (hashed session tokens)
txs(txid PK, seq UNIQUE, height, ts)                      -- seq is the ledger order used by the tracer
inputs(txid, n, prev_txid, prev_n)    outputs(txid, n, address, value, spent_by)
addresses(address PK, label, kind)    flags(txid PK, kind, note)   -- labelled entities, flagged thefts
clusters(address PK, cluster)         patterns(id, kind, txid, size, detail)
risk_scores(address PK, score, reasons JSON, updated_at)
cases(id, user_id FK, name, seed_txid, seed_vout, method, max_hops, summary JSON, graph JSON, created_at)
case_hits(id, case_id FK, address, txid, hops, taint, kind, label)
```

## Notes

- Heuristics: common-input ownership (skipping CoinJoin-like txs), one-time change (the only fresh output of a 2-output tx), peel chains (1-in/2-out hops with small payments), fan-out/fan-in (6+ addresses), equal-output mixing (4+ in, 4+ equal out).
- Taint: poison taints every output of a tainted tx; haircut spreads taint in proportion; FIFO consumes inputs in order with tainted units first within each input. The tracer pops spending transactions by `seq`, so inputs are always final before a tx is processed.
- Risk is additive (taint share up to 60, labelled thief 100, mixer output 25, peel 15, fan-out 10), capped at 100, then lifted to 80% of the highest score in the same wallet cluster.
- Hit totals per destination are not de-duplicated across hops; reports say so.
- All data is generated by `sim.py` with a fixed seed and `sim1...` made-up addresses.
